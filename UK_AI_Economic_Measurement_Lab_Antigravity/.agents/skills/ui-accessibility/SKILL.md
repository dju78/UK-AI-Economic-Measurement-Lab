# UI Accessibility Skill

## Build requirements
- semantic HTML and landmarks;
- keyboard-operable interactions;
- visible focus;
- labels/instructions for inputs;
- accessible names for controls;
- no colour-only meaning;
- readable contrast;
- chart data table/equivalent;
- responsive retention of source/method context.

## Verification
Use browser tooling to check core flows at desktop and narrow/mobile widths. Test keyboard navigation manually where automation is insufficient. Record issues and evidence.
