# Phase 0/1 Foundation Skill

Read `@/docs/23_ANTIGRAVITY_PHASE_0_1_EXECUTION_SPEC.md` before acting.

## Procedure
1. Confirm Phase 0/1 is the currently authorised scope.
2. Inspect repository/Git/tooling state.
3. Follow an approved Implementation Plan.
4. Build foundation before UI shortcuts.
5. Use `/source-provenance` for source acquisition and lineage.
6. Use `/statistical-validation` before publishing transformed data.
7. Use `/ui-accessibility` for public pages.
8. Use `/release-gate` at completion.

## Do not
- create AI-GDP or AI-output estimates;
- start disaggregation/classifier/SNA-engine work;
- use invented production data;
- continue beyond the gate.
