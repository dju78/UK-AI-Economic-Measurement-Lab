# UI and Accessibility

Recommended activation: **Model Decision or frontend glob**.

- Target WCAG 2.2 AA for the public prototype.
- Use semantic headings, landmarks, form labels and keyboard-operable controls.
- Do not encode statistical meaning by colour alone.
- Every chart must have an accessible table or equivalent textual representation.
- Method/status/source context must remain available on narrow/mobile layouts.
- Use plain-language explanations for technical statistical concepts without removing necessary precision.
- Do not imitate ONS branding; use a distinct independent visual identity.
