# Testing and Verification

Recommended activation: **Always On**.

- Run relevant tests after each work package.
- A green UI is not proof of correct data.
- Reconcile transformed data to published source controls where possible.
- Add tests for code lists, keys, duplicates, schema, units and missingness.
- Run type/lint/build checks before phase completion.
- Use browser verification for main flows and source links.
- A completion report must list commands run and their actual outcomes.
- Never hide failing tests or mark them skipped merely to obtain a green build without documenting why.
