# 14 — Product Backlog and User Stories

Priority: P0 required for MVP, P1 next, P2 later.

| ID | Priority | User story | Acceptance summary |
|---|---|---|---|
| DATA-01 | P0 | As an analyst, I can see the exact source/vintage of every number | provenance panel available from each value |
| DATA-02 | P0 | As a reviewer, I can verify broad SUT totals | automated validation against source |
| STACK-01 | P0 | As a user, I can explore the AI production stack | nodes, definitions, SNA links, source notes |
| SUT-01 | P0 | As an economist, I can inspect AI-relevant CPA groups | searchable products and supply/demand facts |
| SUT-02 | P0 | As a user, I am warned broad totals are AI + non-AI | warning adjacent to values |
| DIS-01 | P0 | As a methodologist, I can set an AI-share scenario | low/base/high parameters and result |
| DIS-02 | P0 | As a reviewer, I can see the formula | formula and parameter values visible |
| DIS-03 | P0 | As a researcher, I can compare methods | comparison table/chart |
| DIS-04 | P0 | As a user, I can export a reproducibility object | JSON/CSV download |
| CLS-01 | P1 | As a data scientist, I can classify demo business text | multi-label output + model version |
| CLS-02 | P1 | As a reviewer, I can correct a classification | review workflow stores decision |
| CLS-03 | P1 | As a reviewer, I can inspect model metrics | validation page, confusion/error analysis |
| SNA-01 | P1 | As an economist, I can test an AI-spend scenario | deterministic decision path |
| GAP-01 | P1 | As a researcher, I can see unresolved measurement gaps | gap register with evidence/status |
| QA-01 | P0 | As a reviewer, I can see test/validation status | public quality page |
| A11Y-01 | P0 | As a keyboard/screen-reader user, I can use core flows | WCAG-oriented audit passes |
| REL-01 | P0 | As a user, I can identify the app version/data vintage | global version/vintage display |
| REL-02 | P0 | As a reviewer, I can see revisions and known issues | changelog and issue register |
| TRADE-01 | P2 | As an economist, I can explore AI imports/exports | add when suitable source values exist |
| REG-01 | P2 | As a researcher, I can explore regional producer patterns | methodology and disclosure rules first |

## Backlog discipline

Each analytical story must include: source dependency, statistical acceptance criteria, software tests, accessibility requirements and documentation update.
