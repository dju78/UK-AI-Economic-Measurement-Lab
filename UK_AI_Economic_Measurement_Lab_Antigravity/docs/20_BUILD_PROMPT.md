# 20 — Google Antigravity Build Entry Point

This project is built with **Google Antigravity**.

Do not use a generic one-shot coding prompt. Antigravity should use its project Rules, Skills, specialist agents and Implementation Plan artifact workflow.

## First build action

1. Open the repository root as a Google Antigravity Project.
2. Start a fresh conversation in **Planning Mode**.
3. Paste the contents of:

`prompts/00_FIRST_ANTIGRAVITY_PROMPT.md`

4. Review the generated Implementation Plan artifact.
5. Only after approval, paste/use:

`prompts/01_EXECUTE_APPROVED_PHASE_0_1.md`

6. At completion, run an independent fresh review using:

`prompts/02_PHASE_0_1_INDEPENDENT_REVIEW.md`

7. If gaps are found, use:

`prompts/03_FIX_REVIEW_GAPS_ONLY.md`

Phase 2 is not authorised until the human reviewer accepts the Phase 0/1 gate.
