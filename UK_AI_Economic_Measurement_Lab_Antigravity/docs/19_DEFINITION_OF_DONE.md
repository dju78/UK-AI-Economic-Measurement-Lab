# 19 — Definition of Done

A feature is not done because it renders. It is done when all applicable items below pass.

## Statistical
- research question defined;
- concept/population/reference period defined;
- source suitable and documented;
- output status identified: published / derived / prototype;
- assumptions visible;
- uncertainty handled;
- limitations written;
- result independently checked.

## Data
- raw source immutable;
- source hash and metadata stored;
- schema validation passes;
- transformed data reproducible;
- data-vintage shown.

## Software
- unit tests pass;
- integration tests pass;
- no secrets;
- errors handled;
- performance acceptable;
- code reviewed.

## UX/accessibility
- keyboard usable;
- headings semantic;
- chart table alternative;
- plain-English interpretation;
- mobile layout acceptable;
- no colour-only meaning.

## Documentation
- method card updated;
- source register updated;
- changelog/ADR updated if needed;
- known issues updated.

## Public-release gate
- validation report signed off;
- independent-prototype disclaimer visible;
- GitHub tag created;
- rollback path known.
